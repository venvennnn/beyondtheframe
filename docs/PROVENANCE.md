- `football.mp4` is a byte-for-byte local copy of the user-supplied `videoplayback (40) (online-video-cutter.com).mp4`: H.264, 854×480, 25 fps, 358 frames, 14.32 seconds. Redistribution rights are unknown.
- `football-analysis.json` is generated by the local automatic pipeline adapted from notebook (4), using the same public football player and pitch models. The bundled studio profile skips ball inference and scorer attribution; the optional full pipeline retains ball detection. It contains per-frame coordinates rather than the old burned-in replay. Exact video/model hashes, pipeline version and Ultralytics version are included in the JSON. No player boxes are drawn by hand.
- `football-poster.jpg` is a still from the supplied clip. Screenshot references supplied on 23 October 2026 guide the UI design only; their player labels, arrows, team names and metrics are not copied as evidence for this clip.
- Version 2 adds two-group torso LAB appearance clustering, explicitly labelled tentative. Neither team identity, shirt number, player identity nor scorer identity is verified.
- Hypothetical passing paths use frozen observed positions with explicit geometric assumptions. They are not alternate match footage, trained pass probabilities or inferred future trajectories.
- The detective animation, captions, evidence records and all detective interface screens are removed from the application. Older rendered notebook videos and images are no longer packaged; the client draws its own interactive overlays from coordinates.
- `pipeline/notebook_pipeline.py` retains the supplied notebook's readable functions. Roboflow pitch configuration attribution is retained in `notebook-license.md`. Ultralytics and model/dataset licensing remain separate.
- Launcher icons, banner and SVG UI icons are locally drawn. No stock imagery, external fonts, AWS calls or embedded API credentials are used.

No public hosting or Appstore submission has been performed. The APK remains a local development build with user-supplied sports footage.
